# C++ Command-Line Calculator

A simple, interactive command-line calculator built in C++ to learn the fundamentals of Git, GitHub, and version control workflows.

## 🚀 Features
* **Addition:** Add two numbers together.
* **Subtraction:** Subtract the second number from the first.
* **Git Clean:** Includes a `.gitignore` to keep compiled binaries out of the repository history.

## 🛠️ How to Compile and Run

To run this project locally, make sure you have a C++ compiler installed (like `g++`).

1. Open your terminal and navigate to the project folder.
2. Compile the code:
   ```bash
   g++ main.cpp -o calculator
3. Run the executable:
   ```bash
   Mac/Linux: ./calculator
   Windows: calculator.exe

## 🧠 What I Learned

- Staging and committing changes (git add, git commit).
